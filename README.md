# Shubhi Dixit — Portfolio

Personal portfolio website for Shubhi Dixit, Computer Science undergraduate at Delhi Technological University.

## Features

- Four switchable themes: Pearl, Sage, Lavender and Graphite
- Responsive project showcases using real project screenshots
- Projects, skills, research/campus journey, achievements and contact sections
- Seven certificate/credential cards with certificate previews
- GitHub Pages deployment workflow
- No build step or framework required

## Run locally

```powershell
cd "C:\Users\Shubhi Dixit\Downloads\shubhi-portfolio"
python -m http.server 5500
```

Open `http://localhost:5500`.

## Deploy

The included GitHub Actions workflow deploys the static site to GitHub Pages on pushes to `main`.
